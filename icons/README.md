# PWA Icons for Miles Waite Portfolio

This directory contains app icons for the Progressive Web App (PWA) installation.

## Required Icons

The following icon sizes are needed for full PWA support:

- `icon-72x72.png` - Small icon for Android
- `icon-96x96.png` - Medium icon for Android
- `icon-128x128.png` - Standard icon size
- `icon-144x144.png` - Windows tile icon
- `icon-152x152.png` - iOS home screen icon
- `icon-192x192.png` - Android home screen icon
- `icon-384x384.png` - Large Android icon
- `icon-512x512.png` - Large icon for app stores

## Icon Guidelines

- **Format**: PNG with transparency
- **Design**: Should represent your portfolio/brand
- **Colors**: Match your site's theme (#6366f1 primary color)
- **Style**: Clean, professional, recognizable at small sizes
- **Background**: Can be transparent or solid color

## Shortcut Icons

Additional icons for app shortcuts:
- `shortcut-projects.png` - Projects section shortcut
- `shortcut-music.png` - Music section shortcut  
- `shortcut-code.png` - Code section shortcut
- `shortcut-about.png` - About page shortcut

## Generation

You can generate these icons from your existing favicon or create new ones using:
- Online PWA icon generators
- Design tools like Figma, Sketch, or Adobe Illustrator
- AI image generation tools
- Your existing brand assets
