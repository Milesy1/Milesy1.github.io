# Assets Folder Structure

This folder contains all media assets organized by project categories and types.

## 📁 Folder Structure

```
assets/
├── projects/                    # Creative technology projects
│   ├── audio-reactive-abstract-geometry/
│   ├── particle-systems/
│   ├── api-text-dat/
│   └── generative-max-for-live-tools/
├── music/                       # Music and audio projects
│   ├── audio-reactive-visuals/
│   ├── live-performance/
│   ├── generative-music/
│   └── max-for-live-tools/
└── code/                        # Code and development projects
    ├── touchdesigner/
    ├── python/
    ├── systems-architecture/
    └── creative-coding/
```

## 📂 Media Types

Each project folder contains the following subdirectories:

- **`videos/`** - Video demonstrations, tutorials, and showcases
- **`images/`** - Screenshots, renders, and visual documentation
- **`audio/`** - Audio samples, music tracks, and sound effects
- **`code/`** - Source code, scripts, and project files
- **`docs/`** - Documentation, README files, and project notes
- **`thumbnails/`** - Small preview images for cards and galleries

## 🎯 Usage Guidelines

### File Naming Convention
- Use lowercase with hyphens: `project-demo-video.mp4`
- Include version numbers: `particle-system-v2.1.py`
- Add descriptive suffixes: `audio-reactive-demo-1080p.mp4`

### File Organization
- **Videos**: Keep under 50MB for web optimization
- **Images**: Use WebP format when possible, PNG for transparency
- **Audio**: MP3 for web, WAV for high quality
- **Code**: Include comments and documentation
- **Thumbnails**: 300x200px for consistent card display

### Content Types by Project

#### Projects
- **Audio Reactive Abstract Geometry**: TouchDesigner patches, Python scripts, demo videos
- **Particle Systems**: 3D renders, simulation videos, code examples
- **API Text DAT**: Data visualization examples, API integration code
- **Generative Max for Live Tools**: Ableton Live devices, Max patches

#### Music
- **Audio Reactive Visuals**: Live performance videos, TouchDesigner setups
- **Live Performance**: Event recordings, installation documentation
- **Generative Music**: Algorithmic compositions, Max for Live devices
- **Max for Live Tools**: Custom devices, patches, tutorials

#### Code
- **TouchDesigner**: Project files, Python extensions, documentation
- **Python**: Scripts, libraries, automation tools
- **Systems Architecture**: Diagrams, documentation, case studies
- **Creative Coding**: Processing sketches, generative art code

## 🚀 Adding New Content

1. **Choose the appropriate project folder**
2. **Select the correct media type subfolder**
3. **Follow the naming convention**
4. **Update project documentation if needed**
5. **Add thumbnails for visual content**

## 📝 Maintenance

- Regularly optimize file sizes for web delivery
- Update thumbnails when content changes
- Keep documentation current with project updates
- Archive old versions in `docs/` folders
